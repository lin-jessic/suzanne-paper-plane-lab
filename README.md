# Suzanne 紙飛機飛行實驗室

一個為國小課堂設計的互動式紙飛機飛行模擬器。學生可以調整 Suzanne 紙飛機的迴紋針配重、投擲角度、力道、風向與天氣，觀察飛行距離、高度、滯空時間和側偏變化。

![飛行模擬器](assets/flight-simulator.png)

## 功能

- Suzanne 紙飛機 3D 模型與平滑飛行動畫
- 機身、左翼、右翼及左右對稱迴紋針配重
- 距離、高度、滯空時間、重心與側偏估算
- 正面風、左側風與右側風控制
- 晴天、下雨與颱風環境
- 颱風亂流、斜向暴雨、風粒子與樹木搖晃
- 側視、跟隨與全景觀看模式
- 慢動作重播與飛行關鍵事件提示
- 適合手機、平板及桌面電腦的響應式介面

![試飛結果](assets/flight-simulator-result.png)

## 關卡與成就

左側「關卡挑戰」提供起飛練習、遠距飛行、高度挑戰、側風平衡、雨中飛行共 5 關。每關取得至少 1 星後解鎖下一關，關卡卡片列出各星級條件，可不限次數重試。

闖關時環境固定，螺旋槳停用；第 1 關只調投擲，第 2 關開放配重，第 3 關起開放機型調整。自由實驗仍可使用所有功能。

「成就紀錄」顯示各關最高星級、挑戰次數、成功試飛的最佳成績，以及首次過關與三星成就的取得日期。重播不計次、不授予成就。進度自動存在目前瀏覽器的 localStorage，重新整理會保留；清除網站資料或更換瀏覽器不會保留。

執行 `npm test` 可驗證評分邊界、依序解鎖、存檔與五關三星目標的可達成性。

## 技術

- React 19
- Vite 7
- Three.js
- Lucide React

## 本機執行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可使用。

## 正式建置

```bash
npm run build
```

輸出檔案位於 `dist/`。專案使用相對資源路徑，因此可將 `dist` 內容部署到 XAMPP 的子資料夾，例如：

```text
C:\xampp\htdocs\paperplane\
```

## 課堂用途

建議讓學生先建立基準試飛，每次只調整一個變因，先預測結果再重新試飛，比較配重、風向與環境對飛行的影響。
